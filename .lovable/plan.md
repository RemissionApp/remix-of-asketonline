## Доработка админ-панели `/admin`

Цель: дать тебе все ключевые цифры о пользователях, доходах, удержании и здоровье системы — чтобы понимать, что улучшать.

### Как зайти
- Логин под `info@remissionsoft.com` → перейти на `https://asceta.app/admin` (или preview URL + `/admin`).
- Роль `admin` уже выдана. Если редиректит — перезайти.

### Что добавляем (4 новых раздела + апгрейд существующих)

#### 1. Раздел «Доходы» (новый, главный)
Источник: таблица `subscriptions` + при необходимости Stripe API через edge-функцию.
- KPI: **MRR**, **активные Pro**, **новые Pro за период**, **отменённые** (cancel_at_period_end), **trial → paid конверсия**, **ARPU**, **расчётный churn % за месяц**.
- График: выручка по дням (по `current_period_start`).
- Таблица: последние 50 платных подписок (email, план, статус, started, period_end, cancel_at_period_end).
- Сегмент: разбивка по `product_id` / `price_id` (месячная vs годовая, если есть).

#### 2. Раздел «Retention и когорты» (новый)
- **D1 / D7 / D30** ретеншн (по `page_views` / `user_events` после `created_at` пользователя).
- Когортная таблица: недели регистрации × недели жизни, ячейки — % вернувшихся.
- Топ-фичи по уникальным пользователям за период (вопросы Вселенной, звонки, миссии, медитации, аскезы, нумерология).

#### 3. Карточка пользователя (новый, drill-down из таблицы Users)
Клик по строке → модалка/страница `/admin/users/:id`:
- Профиль, подписка, trial, минуты звонков по месяцам.
- Активные аскезы и прогресс, последние миссии, последние вопросы Вселенной.
- Лента последних 50 событий (`user_events`) и страниц (`page_views`).
- Push-подписки (active/inactive).
- Действия: **Выдать Pro вручную**, **Сбросить дневные лимиты**, **Удалить аккаунт** (через `batch_delete_user_data`).

#### 4. Раздел «Здоровье» (новый)
- Ошибки edge-функций (через analytics_query → `function_edge_logs` со status_code ≥ 500) за период.
- Подписки в `past_due` и `incomplete`.
- Push-подписки: всего активных vs отключённых.
- Последние 20 неудачных Stripe-событий (из `stripe_events` по типу).

#### 5. Апгрейд существующих
- **Overview**: добавить блок «Сегментация» — устройства (mobile/desktop) и referrer-домены (top 10) из `page_views`.
- **Users**: добавить колонки «Последний визит» и «Последняя оплата», сортировку по столбцам, экспорт CSV.
- **Pages/Events**: добавить экспорт CSV и фильтр по платформе.
- Селектор периода уже есть — пробросить во все новые разделы.

### Архитектура (технические детали)
- **Backend**: расширяем существующий edge-function `admin-analytics` новыми `action`'ами:
  - `revenue` — агрегаты по subscriptions
  - `retention` — когорты по `auth.users` + `page_views`/`user_events`
  - `feature-usage` — DAU по фичам
  - `user-detail` (`{ userId }`) — всё по одному юзеру
  - `health` — ошибки + проблемные подписки
  - `admin-action` (`{ type, userId, payload }`) — выдать Pro / сбросить лимит / удалить
- **Auth внутри функции**: проверка `has_role(auth.uid(), 'admin')` через service role перед любым запросом (admin actions требуют отдельной проверки).
- **CSV-экспорт**: формирование в edge-функции, отдача `text/csv`.
- **Frontend**: 4 новых файла в `src/components/admin/sections/` (`Revenue.tsx`, `Retention.tsx`, `UserDetail.tsx`, `Health.tsx`), вкладки добавляем в `AdminPage.tsx`. Карточка пользователя — модалка `Dialog` из shadcn.
- **Stripe-данные**: основное берём из локальной таблицы `subscriptions` (быстро). MRR считаем по активным/trialing с известными ценами (захардкодим прайс-мап `pro_monthly` / `pro_yearly` с amount).

### Что выйдет в итоге
6 разделов: Обзор · Доходы · Пользователи (+карточка) · Retention · Страницы · События · Воронки · Здоровье.
Все цифры за выбранный период, экспорт CSV там, где есть таблица.
