# План: починка звонков + новый дизайн экрана

## Часть 1. Почему звонок может не работать

В коде нашёл несколько потенциальных причин (в логах edge-функции `elevenlabs-conversation-token` — пусто, значит запрос либо не доходит, либо падает до неё):

1. **Жёстко зашитые `agent_id`** в `useElevenLabsConversation.ts` (RU/EN/ES). Если эти агенты в кабинете ElevenLabs удалены/переименованы — токен не выдаётся, фронт получает 502.
2. **Микрофон в WebView (iOS/Android Capacitor)** — `navigator.mediaDevices.getUserMedia` без явного permission через `@capacitor/microphone` и без `NSMicrophoneUsageDescription` в Info.plist приведёт к мгновенному отказу.
3. **Лимит минут**: edge-функция возвращает `429 monthly_minutes_exceeded` ещё до выдачи токена, а UI показывает только generic "Ошибка соединения". Юзер не понимает, что лимит исчерпан.
4. **Отсутствие диагностики** — toast говорит "Failed to connect", но не различает: нет микрофона / нет токена / лимит / network.

### Что сделаю
- Перехватить ответ edge-функции и показывать конкретный текст: "лимит исчерпан", "разрешите микрофон", "агент недоступен", "нет сети".
- В `useElevenLabsConversation` добавить проверку `agentId` и фолбэк на EN, плюс детальный лог.
- Проверить `ios/App/App/Info.plist` на `NSMicrophoneUsageDescription` (если нет — добавить) и `android/.../AndroidManifest.xml` на `RECORD_AUDIO`.
- Запустить тест edge-функции и посмотреть логи — подтвердить, какой именно сценарий ломается.
