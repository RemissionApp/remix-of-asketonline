## Проблема

В правой колонке главной страницы (десктоп) карточка «Гороскоп на сегодня» останавливается на полпути и показывает обрывок текста (например, «…ля получения вашего персональ|» с мигающим курсором), а целое предложение не появляется.

## Причина

В `src/hooks/useBriefHoroscope.ts`:

1. Эффект «печатной машинки» зависит только от `horoscope`, но в условии использует `isTyping`:
   ```ts
   useEffect(() => {
     if (horoscope && !isTyping) { ...старт интервала... }
   }, [horoscope]);
   ```
2. `fetchHoroscope` пересоздаётся при каждом изменении ссылки `userProfile`/`user` (через зависимости), а сам эффект загрузки имеет в зависимостях и `userProfile`, и `fetchHoroscope`. На любом ре-рендере стор может выдать новую ссылку `userProfile` → эффект повторно вызывает `fetchHoroscope` → создаётся новый объект `{ description }` → меняется ссылка `horoscope`.
3. Когда `horoscope` обновляется во время печати, cleanup гасит старый `setInterval`, а новый запуск не стартует, потому что `isTyping === true` (а `isTyping` не в deps). Печать «замораживается» на случайном символе.

## План правки (только фронтенд, файл `src/hooks/useBriefHoroscope.ts`)

1. Переписать эффект печати так, чтобы он всегда корректно перезапускался при смене `horoscope`:
   - убрать ветку `!isTyping`;
   - при каждом новом `horoscope` сбрасывать `displayedText` в `''`, ставить `isTyping = true`, запускать интервал;
   - в cleanup гасить интервал и выставлять `isTyping = false`;
   - если `horoscope?.description` пустой — просто очищать состояние без интервала.
2. Стабилизировать загрузку, чтобы лишних переустановок `horoscope` не было:
   - в зависимостях основного `useEffect` оставить только `user?.id`, `userProfile?.birthDate`, `language` (и убрать `userProfile` целиком и `fetchHoroscope`);
   - у `fetchHoroscope` оставить тот же набор зависимостей, что и сейчас (`userProfile?.birthDate`, `language`), убрать `user` оттуда — внутри он не используется.
3. Чтобы не создавать новый объект `{ description }` при идентичном тексте, сравнивать с предыдущим `horoscope?.description` и вызывать `setHoroscope` только если строка реально изменилась. Это полностью устранит ложные перезапуски печати.

## Что НЕ меняем

- Вёрстка карточки в `DesktopMainExtras.tsx` уже исправлена в прошлый раз (перенос строк, без обрезки) — трогать не нужно.
- Логика edge function `fetch-horoscope` и кэш в `localStorage` остаются как есть.

## Проверка

После правки на десктопной главной (≥ lg):

- текст «Гороскоп на сегодня» полностью допечатывается до конца предложения;
- курсор пропадает в конце, кнопка «Сохранить в Книгу Ответов» становится активной;
- при ре-рендерах профиля печать не сбрасывается посередине.
