# Настройка RevenueCat Paywalls

## Шаг 1: Установка зависимостей

Убедитесь, что установлен пакет для UI:

```bash
npm install @revenuecat/purchases-capacitor-ui
```

## Шаг 2: Настройка в RevenueCat Dashboard

### 2.1 Создание Paywall

1. Войдите в [RevenueCat Dashboard](https://app.revenuecat.com/)
2. Перейдите в раздел **"Paywalls"**
3. Нажмите **"+ New paywall"**
4. Выберите **Offering** (ваше предложение подписок)
5. Выберите **Template** или создайте с нуля

### 2.2 Настройка дизайна Paywall

#### Основные настройки:

- **Название**: "Premium Paywall" или "Asket Premium"
- **Заголовок**: "Откройте полный потенциал"
- **Подзаголовок**: "Получите доступ ко всем премиум функциям"

#### Функции (Features):

1. **Неограниченные вопросы к Вселенной** ⭐
2. **Полные гороскопы и нумерология** 🔮
3. **Расширенные медитации** 🧘‍♀️
4. **Персональные миссии** 🎯
5. **Приоритетная поддержка** 💬

#### Цветовая схема:

- **Основной цвет**: Purple (#8B5CF6)
- **Акцентный цвет**: Pink (#EC4899)
- **Фон**: Белый/Светлый

### 2.3 Настройка продуктов

Убедитесь, что в **Product Catalog** настроены:

- **Ежемесячная подписка** (например, $4.99/месяц)
- **Годовая подписка** (например, $39.99/год)
- **Пожизненная покупка** (например, $99.99)

### 2.4 Настройка Offerings

В разделе **"Product catalog"** → **"Offerings"**:

1. Создайте Offering с названием "Premium"
2. Добавьте пакеты подписок
3. Настройте **Entitlements** для премиум функций

## Шаг 3: Публикация Paywall

1. Переключите Paywall с **"Inactive"** на **"Published"**
2. Убедитесь, что Paywall связан с правильным Offering

## Шаг 4: Тестирование

### 4.1 На реальном устройстве:

```typescript
// В компоненте
const { presentPaywall } = useRevenueCat();

const handleShowPaywall = () => {
  presentPaywall(); // Покажет default offering
};
```

### 4.2 Проверка работы:

- Paywall должен открываться при нажатии кнопки
- Должны отображаться все настроенные продукты
- Покупка должна проходить успешно
- Статус подписки должен обновляться

## Шаг 5: A/B тестирование

### 5.1 Создание эксперимента:

1. В разделе **"Experiments"** создайте новый эксперимент
2. Выберите **"Paywall"** как тип эксперимента
3. Настройте варианты Paywall для тестирования

### 5.2 Метрики для отслеживания:

- **Conversion Rate** (конверсия в покупку)
- **Revenue per User** (доход с пользователя)
- **Time to Purchase** (время до покупки)

## Шаг 6: Аналитика

### 6.1 Отслеживание в Dashboard:

- **Charts** → **Paywall Performance**
- **Customer Journey** → **Paywall Interactions**
- **Revenue** → **Paywall Revenue**

### 6.2 Ключевые метрики:

- Показы Paywall
- Конверсия в покупку
- Средний чек
- Retention после покупки

## Устранение неполадок

### Paywall не открывается:

1. Проверьте, что Paywall опубликован
2. Убедитесь, что Offering настроен правильно
3. Проверьте логи в консоли

### Ошибки покупки:

1. Проверьте настройки Google Play Console
2. Убедитесь, что тестовые аккаунты добавлены
3. Проверьте API ключи RevenueCat

### Проблемы с дизайном:

1. Проверьте настройки Paywall в Dashboard
2. Убедитесь, что все элементы настроены
3. Проверьте на разных устройствах
